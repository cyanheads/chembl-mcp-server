# 0.3.3 — 2026-10-10

## Changed

- **Tool errors** carry request IDs from mcp-ts-core 0.13.10; declared recovery hints remain intact after redundant `ctx.recoveryFor()` forwarding is removed.
- **Docker dependencies** use the framework's OTel peer installer, prune musl-only packages from the glibc runtime, and exclude installation-only scanner and configuration files.
- **Framework guidance** and `.env.example` track current configuration, error handling, testing, and release procedures; the README SDK badge tracks ^2.2.0.
- **Packaging checks** cover registry npm launch arguments and target-platform JavaScript execution; tracked-secret, TODO, and framework antipattern scans use portable matching.
- **Package exclusions** cover environment and registry-token files, caches, and development directories; CodeQL uploads each language under its matching analysis category.

## Fixed

- **Search and bioactivity arguments** accept numeric-string limits, phase and potency filters, and null optional arguments through mcp-ts-core 0.13.14; invalid numeric strings still reject before upstream calls.
- **Resource parameter errors** lead with the failing field path through mcp-ts-core 0.13.12.
- **Registry npm launch metadata** uses `npx` without npm-script arguments and fixes `MCP_TRANSPORT_TYPE=http` on the HTTP entry.
