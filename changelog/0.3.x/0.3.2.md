# 0.3.2 — 2026-09-26

## Fixed

- **Multi-platform Docker builds** install production dependencies in a native `BUILDPLATFORM` stage, avoiding Bun/Socket scanner crashes under amd64 emulation ([#24](https://github.com/cyanheads/chembl-mcp-server/issues/24)).
- **Target-architecture dependencies** use explicit Bun `--cpu`/`--os` selection for the frozen install and optional OpenTelemetry peers, then copy the production tree into the slim runtime. Socket scanning, the three-day release-age guard, and framework peer ranges remain enforced.
