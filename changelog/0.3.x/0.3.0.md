# 0.3.0 — 2026-09-19

## Changed

- **`canvas_id` inputs now validate against the minted id shape** (`^[A-Za-z0-9_-]{10}$`) on `chembl_get_bioactivities`, `chembl_dataframe_query`, `chembl_dataframe_describe`, and `chembl_dataframe_drop`. **Breaking:** an id that was never minted by this server is now rejected at argument validation instead of reaching the canvas and reading as expired; the `canvas_id` this server *returns* on `chembl_get_bioactivities` is unaffected, still a plain string.
- **`sessionMode: 'stateless'`** is now declared in `src/index.ts` rather than left to `MCP_SESSION_MODE`'s `auto` default — a source run, the container, and `.env.example` resolve alike, and the server card now publishes the resolved mode.
- **Tool error text closes with `(reason … · not retryable)`** whenever `data.reason` or `data.retryable` is set, and an argument rejection carries a schema-derived `Recovery:` hint — both from the framework bump, no server-side change.
- **A caller disconnect mid-call now classifies as `RequestCancelled` (-32011)** instead of `InternalError`, and an upstream 500 retries once as transient `ServiceUnavailable` instead of failing on the first attempt — relevant to `chembl_get_drug_info`'s `Promise.allSettled` composition, where a transient ChEMBL blip on the mechanisms/indications endpoints now more often resolves instead of degrading to `failed`.
