# 0.3.1 — 2026-09-26

## Changed

- **Upstream error contracts** declare the existing service-raised `not_found` and `rate_limited` reasons on five tools and both resources.
- **Framework error data** inherits removal of `originalStack` and `causeChain` in 0.13.7 and request context fields in 0.13.8. Malformed cursors carry `invalid_cursor` recovery; output-contract failures use `-32603` instead of `-32007` (0.13.8).
- **Argument handling** inherits safe-integer-to-string repair and field-specific recovery hints from framework 0.13.9. Repairs apply only when the corrected arguments pass the schema.
- **HTTP protocol validation** inherits MCP SDK 2.1.0 through framework 0.13.9: 2026-07-28 POSTs require `MCP-Protocol-Version`, and batches over 100 messages are refused.
- **Telemetry configuration** documents the base trace/metric endpoint fix from framework 0.13.7, plus explicit OTLP log export and failed-call payload logging opt-ins from 0.13.8. Payload redaction matches key names, not secrets embedded in free-form values.
- **Canvas storage** inherits private scratch directories, isolated concurrent spills, and corrected DuckDB error classification from framework 0.13.9. `CANVAS_TEMP_PATH` names the parent directory.
- **Docker installs** preserve the three-day release-age guard and Socket scanning in production, install telemetry packages within the framework's peer ranges, and include optional OTLP log peers.
- **Packaging and development tooling** exclude built MCPB bundles from npm and logs/design notes from MCPB, sync framework skills, and add definition-load, manifest-version, Docker build-platform, and release-tag checks.
- **Deployment documentation** clarifies the existing stateless declaration and meaningful `MCP_SESSION_MODE` override, and corrects the description of target-architecture DuckDB installation.

## Fixed

- **`chembl_get_bioactivities` canvas precision** preserves fractional `pchembl_value` and `standard_value` after sparse or integer-only previews in both potency views, retaining null measurements and original text ([#20](https://github.com/cyanheads/chembl-mcp-server/issues/20)).
