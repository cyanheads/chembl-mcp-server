# 0.5.0 — 2026-10-28

## Added

- **`chembl-guide` Agent Skill** — gates and workflows for pinning a protein to its single-protein target, ranking leads without mixing mutants, salts, or repeat measurements, reading selectivity with the inactive results, and checking assay provenance and approval status. Served over MCP as `skill://chembl-guide/SKILL.md` (with the `skill://{+path}` template for its reference file) through `createApp({ skills: 'skills' })`, and shipped in the npm package, the Docker image, the `.mcpb` bundle, and plugin installs.

## Changed

- **Skills served over MCP** through `createApp({ skills })` — mcp-ts-core 0.13.18 ([cyanheads/mcp-ts-core#789](https://github.com/cyanheads/mcp-ts-core/issues/789)).
- **MCP SDK `@modelcontextprotocol/server` 2.3.1 → 2.4.0** — mcp-ts-core 0.13.17.
- **Tool error text in `content[]` renders as written.** The `Error:` message, `Recovery:` hint, and `reason` gain Markdown escapes; `structuredContent` is unchanged — mcp-ts-core 0.13.16 ([cyanheads/mcp-ts-core#760](https://github.com/cyanheads/mcp-ts-core/issues/760)); a trailing ` #` gains its escape in 0.13.18 ([cyanheads/mcp-ts-core#781](https://github.com/cyanheads/mcp-ts-core/issues/781)).
- **Out-of-range framework env values stop startup** (fractional ports and counts, out-of-range timers) instead of being accepted — mcp-ts-core 0.13.16.
- **CORS exposes `WWW-Authenticate` and `Retry-After`** — mcp-ts-core 0.13.16.
- **The `.mcpb` bundle drops framework build-only files and node-gyp output** — mcp-ts-core 0.13.18. It keeps the MCP SDK's own skills runtime through a local fix in `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts` ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), still open upstream).
- **Agent Plugins root `plugin.json` and `mcp.json`, and a root-anchored `.mcpbignore`** — template adoption from mcp-ts-core 0.13.18.
- **`minimumReleaseAge`** in `bunfig.toml` is 1 day (was 3).

## Fixed

- **`max_phase` descriptions state ChEMBL's scale** on `chembl_search_molecules` rows and `chembl_get_drug_info` (and its indications' `max_phase_for_ind`): 4 approved, 3–1 trial phase, 0.5 early phase 1, −1 clinical with the phase unknown, null no clinical record. They said "0 = research compound" and "(1–4)"; ChEMBL records no 0.
- **`chembl_get_assay` `organism` description** states it is the assay's own organism, null even when the target is human.
